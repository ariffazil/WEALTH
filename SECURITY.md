# Security Policy

## Supported Versions

Only the latest release of WEALTH is active and supported for security updates.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ Yes     |

## Reporting a Vulnerability

We take the security of WEALTH seriously. If you find a security vulnerability, please do not open a public issue. Instead, report it directly to the project maintainer:

- **Email:** arif@arif-fazil.com
- **Response SLA:** Within 48 hours for triage and initial assessment.

Please include:
1. A description of the vulnerability and its potential impact.
2. Step-by-step instructions or a proof-of-concept (PoC) to reproduce the behavior.
3. Any suggested mitigations.

## Scope

WEALTH is a capital intelligence organ — it computes valuation, risk, and market data. It does NOT move money, authorize transactions, or hold private keys. However, vulnerabilities in its MCP tool surface, data ingestion, or computation engines could lead to misinformed capital decisions. Report anything that could compromise computational integrity.
