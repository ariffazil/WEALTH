## Principles

1. **Each organ measures only what it owns.** arifOS combines signals and governs action.
2. **Observe states, never declare traits.** Temporal, contestable, reversible.
3. **At least one benign alternative explanation is mandatory** for every observation.
4. **J-state uses minimum-floor aggregation.** A near-zero authority or consequence score cannot be averaged away.
5. **No organ reads the soul.** No agent manufactures its own authority.
