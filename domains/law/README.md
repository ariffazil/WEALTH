## Operating rules (carry-over from canon 002)

1. **ADVISORY + FLAGS only.** WEALTH never issues binding verdicts.
2. **Every record is receipted** (T1 minimum, T2 for HIGH/CRITICAL).
3. **Jurisdiction is mandatory** on every record. No silent leaps.
4. **HIGH/CRITICAL ⇒ 888_HOLD.** The tool returns HOLD, not advice.
5. **No cross-jurisdiction synthesis** without explicit `cross_jurisdiction_notes`.
6. **No self-judging** the geometry. arifOS + 888 do that.

## Anti-patterns

These fail the canon on receipt and must be fixed before merge:

- "This is illegal" / "You must do X" — verdict language. Forbidden.
- Tool returning a HIGH advisory without `888_HOLD` flag.
- Citing an Act without section + gazette version.
- Importing live case text into the pack (separate ledger; not this domain).
- Tool claiming to "understand the user's situation" — empathy drift.
